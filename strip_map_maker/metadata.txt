about=Strip Map Maker lays out a numbered series of rotated, overlapping map sheets along a line such as a road, pipeline, river or power line. Select or draw the line, choose sheet size, scale, overlap and optional smoothing, and the plugin stores the sheets in a GeoPackage with sheet number, bearing and distance along the line. The result can be used as a QGIS Atlas coverage layer or as a sheet index for planning, inventory and environmental surveys. The guide line must be in a projected CRS in metres (the project CRS is used when drawing), so the plugin works anywhere on Earth where such a CRS exists. It uses no external services or extra Python packages. The interface is in English and has a complete Swedish translation, used when QGIS is set to Swedish.
